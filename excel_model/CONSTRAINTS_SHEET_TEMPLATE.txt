================================
SHEET: CONSTRAINTS
================================

Each constraint has: Left Side | Operator | Right Side

If C60 shows "INFEASIBLE", you need to relax some constraints or increase capacity limits.

================================
OPENSOLVER CONFIGURATION:
================================

When setting up OpenSolver:

1. Go to Data > OpenSolver > Open and Solve
2. Target Cell: Objective!$D$50
3. To: Minimize
4. Changing Cells: Variables!$B$7:$Y$44
5. Subject To Constraints: Add all from Constraints sheet
   - Electricity_Demand_North >= (in column D)
   - Electricity_Demand_Central >= (in column D)
   - ... (all energy balance constraints)
   - Coal_Max_Capacity <= (in column D)
   - ... (all capacity constraints)
   - CO2_Emissions_Limit <= (in column D)
   - Renewable_Minimum >= (in column D)

6. Solver: GLPK (free) or Gurobi (commercial)
7. Time Limit: 300 seconds
8. Optimality Gap: 0.01 (1%)

================================
NOTES:
================================

1. Each row is one constraint
2. Green cells = constraint is satisfied (OK)
3. Red cells = constraint is violated (VIO)
4. Adjust right side values if constraints are too restrictive
5. Some constraints are alternatives (e.g., min OR max, not both)
6. All formulas should reference named ranges for clarity
