================================
NOTES:
================================

1. All cells with solver variables should have:
   - Format: Number with 1-2 decimal places
   - Fill Color: Light Green (RGB: 226, 239, 218)
   - Border: All sides

2. Initial values should be 0 or small feasible values

3. Formulas should reference Input_Data sheet for parameters

4. Objective sheet will reference these cells in cost calculations

5. Constraints sheet will define limits on these variables

6. Results sheet will pull optimal values from these cells

================================
OPENSOLVER CONFIGURATION:
================================

Changing Cells: Variables!$B$7:$Y$14
  (New capacity installations for all technologies and years)

Alternatively:
Changing Cells: Variables!$B$7:$Y$44
  (All energy outputs and dispatch decisions)

Depending on model formulation (capacity-based or dispatch-based)
